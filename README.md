# CogniTrack

Skrining perkembangan anak (KPSP) dengan verifikasi dokter. A plain static site (`index.html`, `js/`, `img/`, `fonts/`) with no build step. Deploy the repo root as-is, for example to GitHub Pages.

## Android app

The Android app wraps the same site with [Capacitor](https://capacitorjs.com). It runs fully offline and keeps its data in the WebView's localStorage.

| Path | Purpose |
| --- | --- |
| `www/` | Generated by `npm run build`. It holds a copy of the site plus `capacitor.js`. Not committed. |
| `android/` | The native Android project. Committed. |
| `capacitor.config.json` | Sets the app name, appId `com.malik.cognitrack`, the splash screen, and the status bar. |
| `assets/` | Source images for the icon and splash screen. `scripts/make-icon-sources.cjs` draws them from the favicon. |

Requirements: Node 20+ and Android Studio, which provides the Android SDK and a bundled JDK. Gradle needs Java 17–25. `npm run apk` falls back to Android Studio's JDK when `JAVA_HOME` is unset or points to a newer Java. Gradle downloads the JDK 21 toolchain that some plugins require on the first build.

### Rebuild after editing the website

Edit `index.html`, `js/` or `img/` at the repo root as usual, then run:

```bash
npm install          # first time only
npm run sync         # copies the site into www/ and runs `cap sync android`
npm run apk          # sync + gradlew assembleDebug
```

The debug APK is written to `android/app/build/outputs/apk/debug/app-debug.apk`. You can also run `npx cap open android` and press Run in Android Studio.

To change the icon or splash screen, edit `assets/*.png` (or rerun `node scripts/make-icon-sources.cjs`), then run `npm run assets` followed by `npm run sync`.

### Install the APK on a phone

- **USB:** on the phone, enable *Developer options → USB debugging*, connect it, then run `adb install -r android/app/build/outputs/apk/debug/app-debug.apk`. `adb` is in `~/Library/Android/sdk/platform-tools`.
- **Without a cable:** copy `app-debug.apk` to the phone (Drive, email, etc.), open it, and allow *Install unknown apps* for the app you opened it from.

### Signed release AAB for the Play Store

1. Increase `versionCode` (and `versionName`) in `android/app/build.gradle` for every upload.
2. Create an upload key once, and keep it and its passwords somewhere safe outside the repo. `*.jks` and `*.keystore` are git-ignored.
   ```bash
   keytool -genkey -v -keystore ~/keys/cognitrack-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias cognitrack
   ```
3. Run `npm run sync`, then build the bundle in either of these ways:
   - **Android Studio:** run `npx cap open android`, choose *Build → Generate Signed App Bundle / APK → Android App Bundle*, pick the keystore, and select the `release` variant.
   - **CLI:** note that the passwords end up in your shell history.
     ```bash
     JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" npx cap build android --androidreleasetype AAB --keystorepath ~/keys/cognitrack-upload.jks --keystorealias cognitrack --keystorepass '…' --keystorealiaspass '…'
     ```

   The bundle is written to `android/app/build/outputs/bundle/release/app-release.aab`.
4. Upload the `.aab` in Play Console with Play App Signing turned on.
